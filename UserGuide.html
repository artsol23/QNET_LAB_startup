Q-Net Lab

Обучение и проверка нейросетей для распознавания состояний кудитов и кубитных регистров при дисперсионном считывании сверхпроводниковых кубитов.

1. Установка

  1. Откройте папку QNetLab в PyCharm (File → Open).
  2. Создайте виртуальное окружение (Settings → Project → Python Interpreter → Add Interpreter → Virtualenv), Python 3.10+.
  3. В Terminal PyCharm: 
    python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
  4. Откройте main.py → Run 'main'.

При запуске показывается заставка с полосой загрузки: проверяется RSA-лицензия (license.json + public_key.pem рядом с main.py). Если лицензия недействительна, программа сообщит причину и предложит выбрать другой файл лицензии; без неё главное окно не откроется.

2. Проект

Вся работа ведётся в проекте. Кнопка «Новый проект» — выберите пустую папку. Всё, что создаёт программа, хранится только в ней:

Файл / папкаСодержимое
project.jsonданные проекта, разбиение, реестр весов, история эпох, настройки окна
logs.txtсистемный журнал операций и ошибок
data\копии импортированных данных (или ссылка на файл с SHA-256, если снять флажок «Копировать»), исправленные метки
weights\наборы весов weights_ГГГГММДД_ЧЧММСС.pt — например, полученные в разные дни
logs\журналы обучения по эпохам training_….csv
reports\результаты распознавания (CSV), отчёты (JSON), графики (PNG)

«Открыть проект» — выбрать project.json; восстанавливаются данные, разбиение, текущие веса и настройки. «Загрузить веса» / «Сохранить веса» — работа с наборами весов; при загрузке веса заменяются в нейросети. «Загрузить журнал» — показать сохранённую историю обучения. При закрытии с несохранённой моделью программа предложит сохранить проект.

3. Режимы окна

Кнопка в левом верхнем углу переключает режимы Обучение и Валидация.

Обучение

Слева, вкладка «Обучение»:

  • Данные: загрузка CSV/NPZ, разделение на train/validation/test (стратифицировано по состоянию регистра), поиск естественной утечки в |2⟩ (спектральная кластеризация MTV, §V-A статьи; метки применяются только после подтверждения).
  • Регистр и архитектура: какие атомы (каналы) и сколько их уровней используются; модель «фильтры + FNN» или «FNN по I/Q»; отдельная сеть на атом; число и размер скрытых слоёв (слайдеры или точный список; «авто» = ⌊P/2⌋, ⌊P/4⌋ как в статье); активация; dropout.
  • Фильтры: временное окно; свёрточный фильтр (прямоугольный, гауссов, экспоненциальный или своё ядро); QMF (пары состояний), RMF (распад), EMF (возбуждение); правило поиска трасс-событий; регуляризация.
  • Оптимизатор: Adam / AdamW / SGD / RMSprop, learning rate (слайдер), weight decay, momentum, эпохи, батч; «Создать сеть и обучить»; «Проверить на отложенном test».

Вкладка «Дообучение»: список наборов весов проекта с датами и метриками, загрузка выбранного набора и дообучение (архитектура и фильтры загруженной модели заморожены).

Справа — графики: loss, score (accuracy регистра), assignment fidelity FnQ, macro-F1, XEB, матрица ошибок. Флажками включается любой набор; «Только этот» оставляет один график. Флажки доступны и во время обучения.

Валидация

Слева: вкладка «Фильтры» — загрузка экспериментальных данных и применение фильтров модели (гистограммы выходов QMF/RMF/EMF по классам, доля трасс-событий распада и возбуждения); вкладка «Распознавание» — валидация по меткам, классификация без меток, частоты f01 для оценки температуры, экспорт.

Справа: пятна IQ (MTV, ошибки отмечены крестиком), матрицы ошибок, бенчмарки (нейросеть против центроида, LDA, QDA), распад и температура, гистограммы и ядра фильтров, кривые IQ. Отметьте атомы над графиком — одновременно показывается не более пяти.

4. Метрики

МетрикаОпределение
Score / accuracyдоля измерений, в которых верно распознаны все атомы регистра
Assignment fidelityатома: среднее по уровням P(верно | подготовлен уровень); регистра FnQ — геометрическое среднее по атомам (как F5Q в статье)
XEBесли в данных есть ideal_probs — linear XEB D·⟨pideal(ŝ)⟩−1; иначе XEB по меткам (D·acc−1)/(D−1): accuracy с поправкой на случайное угадывание (0 — угадывание, 1 — идеал), а не независимая квантовая fidelity
Ошибка распада / возбужденияпо матрице: P(предсказан уровень ниже / выше | подготовлен i); «в окне» — доля трасс, у которых начало у уровня i, а конец у уровня ниже/выше (переход во время считывания)
«Ошибка температуры»доля трасс, подготовленных в |0⟩, у которых уже начало трассы в облаке выше — верхняя оценка термальной населённости (включает ошибки подготовки и перекрытие облаков); при заданной f01 — оценка Teff = h·f01 / (kB·ln((1−p)/p))
SNR пятендля пары уровней: расстояние центров MTV / средняя ширина облаков вдоль оси между ними; ошибка перекрытия ≈ Φ(−SNR/2)

5. Форматы файлов

NPZ: iq complex [N,A,T] (или iq [N,A,T,2], или I, Q [N,A,T]); labels int [N,A]; необязательно time_ns [T], shot_ids [N], ideal_probs [D] или [N,D].

CSV длинный: shot,atom,sample,I,Q[,label][,time_ns] — одна строка на отсчёт.
CSV широкий: shot,atom[,label],I_0,…,I_{T-1},Q_0,…,Q_{T-1} — одна строка на трассу атома.
Разделитель (, ; TAB) определяется автоматически.

Веса .pt: конфигурация, веса, фильтры, нормировка, состояние оптимизатора, метаданные. Журнал .csv: столбцы epoch, loss, accuracy, val_loss, val_accuracy, val_assignment_fidelity, val_macro_f1, val_xeb, val_xeb_linear, lr.

6. Типичные сценарии

  1. Обучить классификатор регистра. Новый проект → загрузить examples\demo_register_5x3.npz → атомы 0,1,2,3,4, уровни 3 → «Создать сеть и обучить» → «Проверить на отложенном test» → «Сохранить веса».
  2. Проверить на эксперименте. Режим «Валидация» → «Загрузить экспериментальные данные» (demo_experiment_5x3.npz) → «Применить фильтры к данным» → вкладка «Распознавание» → «Валидировать» → графики справа → экспорт.
  3. Дообучить вчерашние веса. Вкладка «Дообучение» → выбрать набор весов → «Загрузить выбранные» → загрузить новые данные и разделить → «Дообучить».
  4. Кутрит по данным с подготовкой 0/1. Загрузить demo_qubit_leakage_wide.csv → «Поиск утечки в |2⟩» → подтвердить → уровни станут 3 → обучить.
  5. Классифицировать новые данные без меток. Загрузить demo_unlabeled_5x3.npz → «Классифицировать» → «Результаты распознавания (CSV)».
